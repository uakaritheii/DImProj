# DImProj

Plant disease image project using the [PlantVillage dataset](https://github.com/spMohanty/PlantVillage-Dataset).

## Running the notebook

> **Note:** Before running `step1_data.ipynb`, clone the dataset into the root of this repo:
>
> ```bash
> git clone https://github.com/spMohanty/PlantVillage-Dataset
> ```
>
> The notebook uses relative paths such as `PlantVillage-Dataset/raw/color/...`, so the folder must be named `PlantVillage-Dataset` and sit next to the notebook.
